# 思い出して打つモード 設計

日付: 2026-11-02 ／ 対象: typle-r v2.7.0、typle-ipad v0.62.0

## 目的

語学の単語とコマンド・構文の両方で、答え（入力する文字）を見ずに、意味だけを手がかりに思い出して打つ練習をできるようにする。今の練習は表示された文字を写して打つもので、打つ練習にはなるが覚える練習にはならない。

成功の条件:

- 語学パック（「apple / りんご」形式の補足）とコマンドのパック（「cp：ファイルをコピー」形式）の両方で、答えが画面に出ないまま練習を最後まで終えられる。
- 思い出して打った記録が、通常の練習のベスト・推移と混ざらない。
- iPad 版・Mac 版で保存しても、思い出して打った記録が通常の記録に変わらない。

## 範囲外

- iPad 版・Mac 版での思い出して打つモードそのもの（記録を保つ・比べるときに分けることだけ行う）。
- 単語に「問題文」の項目を足すこと（自動で伏せる方法がうまくいかない語が見つかったら、別に設計する）。
- 間隔反復（SRS）や単語ごとのミスの記録。
- 手元専用の `/api/v1` での `mode` 付きの記録の追加（読み取りでは `mode` をそのまま返す）。

## 1. 画面の動き（`/play`）

- 練習画面の上部、ライブ指標の表示ボタンの隣に「思い出して打つ」のトグルを置く。
  - 値はブラウザーごとに `localStorage` の `typle-r:practice-mode`（`recall` のときだけ書く）に保存し、タブ間で同期する（`src/lib/liveStats.ts` と同じ形）。
  - 練習中（入力を始めてから結果が出るまで）は、端末のメニュー（`DeviceMenu` の `locked`）と同じく切り替えられない。
- 思い出して打つモードで見せるもの（上から順に）:
  1. 答えを隠した補足（`recallPrompt`、2章）。空でなければ見せる。
  2. 表示する文字。入力する文字と違い、かつ `input_type` が `code` でないときだけ見せる（例：表示「苹果」、入力 `pingguo`）。
  3. 1も2も見せられないときは「ヒントがありません」。
- 答えの欄:
  - 正しく打った文字はその場で見える（今の緑の表示）。
  - まだ打っていない文字は1文字ずつ「＿」で見せ、文字数だけが分かるようにする。空白は空白のまま見せる。
  - 間違えた文字は今と同じく赤で見せ、ミスに数える。判定（`typeInput`）は変えない。
- 「答えを見る」ボタン:
  - 押すと、その語の残りの文字を見せる。見せた文字の数（コードポイント）をミスと打鍵の数に加える。正確率と速さに、答えを見た分が反映される。
  - 答えを見た後も、自分で打ち切るまで次の語に進まない。
  - 1つの語で2回押しても、ミスは最初の1回分だけ数える。
- 思い出して打つモードの間は、答えが見えるものを隠す: 次の単語のチップ、すべての単語の一覧、簡易入力のキー、「入力する文字」の案内（`TargetText guide`）。
- 結果画面は今と同じ形で、見出しに「思い出して打つ」と出す。ベストとの差は、思い出して打った記録とだけ比べる（3章）。

## 2. 答えの隠し方（`src/core/recallPrompt.ts`）

`recallPrompt(word: Word): string` は、補足から答えを伏せた文字列を返す純粋な関数。空文字を返したときは、画面は1章の 2・3 の順で代わりを見せる。

- 答えの候補: 入力する文字（`input`）、表示する文字（`display`）、入力する文字の先頭のトークン（最初の空白までの部分。2文字以上のとき）。
- 比べ方: 大文字と小文字を区別せず、アクセント記号（Unicode の結合文字）を除いて比べる。
- 補足に「 / 」があるとき: 「 / 」で区切った部分のうち、答えの候補のどれかを含む部分を除き、残りを「 / 」でつないで返す。
  - 例: 「apple / りんご」→「りんご」、「Āfùhàn / アフガニスタン」（入力 `afuhan`）→「アフガニスタン」。
- それ以外のとき: 補足の中の答えの候補（長いものから順に）を「＿＿」に置き換えて返す。
  - 例: 「cp：ファイルをコピー」（入力 `cp -r src dst`）→「＿＿：ファイルをコピー」。
- 置き換えた後に、句読点と空白と「＿」しか残らないときは空文字を返す。

## 3. 記録の保存と比べ方

### 記録の形

- 練習記録に `mode` を足す。思い出して打った記録だけ `"recall"` を持つ。通常の練習では項目を書かない（今ある記録は変わらない）。
- 値は `"recall"` か項目なしだけ。ほかの値は Web 版・サーバーとも不正な記録として拒否する（`invalidRecord`）。

### 比べ方

| 場所 | 使う記録 |
|---|---|
| 結果画面のベスト・差 | 練習したモードと同じ記録 |
| 練習画面の右のベスト5件、リスト一覧・選択肢のベスト | 今のモードと同じ記録 |
| ベスト記録ページ（`/rankings`） | 「通常／思い出す」の切り替えで選んだモード。URL は `?mode=recall`（通常は付けない） |
| ホームの推移・次に練習するリスト・平均正確率 | 通常の記録だけ |
| ホームの今週のまとめ（回数・連続日数・練習時間） | すべての記録 |
| 練習記録ページ（`/records`） | すべての記録。思い出して打った記録に「思い出す」の印を付ける |

語数で比べる仕組み（`comparableRecords`）は、モードで絞った後にそのまま使う。

### 直すところ

- Web（TypeScript）
  - `src/core/records.ts`: `PracticeRecord` に `mode?: 'recall'`。`makeRecord` と `addRecord`（今は知っている項目だけで作り直すので `mode` が消える）。モードで絞る関数 `recordsOfMode`。
  - `src/core/wordLists.ts`: 保存された記録の型と読み込み時の検証。
  - `src/core/rankings.ts`・`dashboard.ts`・`listOverview.ts` と画面: 上の表のとおりに絞る。
  - 記録の追加の API を呼ぶ部分（`workspaceRequest.ts` など）。
- サーバー（Go、`server/internal`）
  - `workspace`: `Record` と `rawRecord`（既知の項目の一覧）に `Mode`、`decodeRecord` での検証、`AddRecord` で `Mode` を保つ、`rank.go` の比べ方をモードで絞る。
  - `web/records.go`: `RecordInput` に `mode` を足す（`DisallowUnknownFields` のままでよい）。
  - `api`（`/api/v1`）: ランキングとダッシュボードは通常の記録だけ。記録の追加は `mode` を受け付けない（範囲外）。
- iPad/Mac（typle-ipad の TypleCore）
  - `StoredRecord` に `mode: String?` を足し、端末内の保存とアカウントの保存の両方で保つ。
  - ベスト・ランキング・推移・次に練習するリストから、`mode` を持つ記録を外す。
  - 練習記録の一覧で「思い出す」の印を付ける（文言を `Shared/Resources/*/Localizable.strings` に足す）。

### 出す順番

1. typle-ipad v0.62.0: `mode` を保ち、比べるときに外す。`mode` を持つ記録がなくても動く。
2. typle-r v2.7.0: Go と Web。

サーバーに `mode` 付きの記録が入る時点で、iPad/Mac 版がすでにそれを保てる。

## 4. テスト

- Web の単体テスト（`tests/*.test.cjs`）
  - `recallPrompt`: 公式パックの実例（英語・中国語・国名・Linux・Go・PostgreSQL のエラーコード）と、空を返す場合。
  - `mode` の検証と保持（ゲスト保存を含む）、`addRecord` で消えないこと。
  - モードで分けて比べること（結果のベスト、ランキング、ダッシュボード）。
  - 「答えを見る」で、残りの文字数がミスと打鍵に1回だけ加わること。
- Go（`go test ./...`）
  - `mode` の検証（`recall` と項目なしだけ通る）。
  - `POST /api/workspace/records` と `PUT /api/workspace` の両方で `mode` が保たれること。
  - `rank.go` の比べ方がモードで分かれること。`/api/v1` のランキングが通常の記録だけを使うこと。
- E2E（Playwright、`tests/e2e/recall.spec.ts`）
  - 思い出して打つモードで練習を1回最後まで行い、保存された記録に `mode: "recall"` があること。
  - 答えが見えるもの（次の単語・すべての単語・入力する文字の案内）が出ないこと。
  - 結果画面とベスト記録ページで、通常の記録と分かれて表示されること。
  - 練習中はトグルを押せないこと。
- TypleCore（`swift test`）
  - `mode` 付きの記録を、端末内の形式とアカウントの形式の両方で読み書きしても `mode` が残ること。
  - ベストとダッシュボードから外れること。
