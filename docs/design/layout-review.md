## 現状の課題

## 改善案

| 改善 | 対応する課題 | 内容 |
|---|---|---|
| トップバーは 56px の1段で固定 | 1, 2, 5 | 左にロゴ（/home へ）、右に保存先・テーマ・アカウント。`sticky top-0`。ロゴは1か所だけにする |
| サイドバーは幅 240px で固定 | 1, 2 | ロゴのブロックと見出し「ナビ」をなくし、最初の項目は y=72。トップバーの下に `sticky`（高さ 100dvh − 56px、はみ出したら縦スクロール）。1024×768 でもヘルプの GitHub（下端 y=756）まで収まる |
| グループと名前 | 4 | 「ホーム」「練習（練習する・練習記録・ベスト記録）」「単語リスト（単語リスト・リストを作成）」「設定（端末）」。名前は画面の見出しにそろえる |
| 現在地 | 4 | 背景・太字・左の縦線（`aria-current="page"`）。項目は高さ 40px、角丸 8px |
| ヘルプを下部にまとめる | 10 | 使い方・Typleについて・GitHub（外部リンクのアイコン）。トップバーの「ガイド」「GitHub」はここへ移す |
| 保存先のチップ | 8, 11 | 「このブラウザーに保存」（HardDrive）／「アカウントに保存」（Cloud）を常に表示し、ホバーで説明。確認中は誤った保存先を見せないよう出さない |
| アカウントメニュー | 9, 11 | 「アカウントメニュー」「端末を管理」「ログアウト」。先頭に名前と「GitHubでログイン中」。確認中はアバターと同じ 40px の枠に丸いスケルトン |
| 本文へスキップ | 7 | 最初の Tab でトップバーの左上に表示し、Enter で本文（`#main-content`）へ移る |
| 高さ | 3 | 本文の最小の高さを 100dvh − 56px にする。移動先の行が固定のトップバーに隠れないよう `scroll-padding-top` を 72px にする |
| モバイル・タブレットはドロワー | 5, 6 | 1023px 以下はトップバー1段（メニュー・ロゴ・テーマ・ログイン）。レールをなくし本文は全幅（390px で 358px）。ドロワーは幅 288px（最大 85vw）で背景を暗くし、Esc・背景のタップ・リンクの選択で閉じてフォーカスをメニューボタンに戻す。開いている間は背景を操作できない。1024px 以上に広げると閉じる |
| ドロワーに保存先とヘルプ | 8, 10 | 640px 未満はトップバーに保存先を出さず、ドロワーの先頭に出す。ログインボタンは「ログイン」と表示し、読み上げは「GitHubでログイン」 |

## 実装メモ

- 主な変更箇所: `src/app/layout.tsx`、`src/components/Navbar/`（`Navbar.tsx`、`Brand.tsx`、`StorageBadge.tsx`、`MobileNav.tsx`）、`src/components/Sidebar/`（`Sidebar.tsx`、`NavList.tsx`、`navigation.ts`）、`src/components/AccountBar.tsx`、`src/components/ThemeSwitcher.tsx`、`src/app/globals.css`
- ナビの項目は `navigation.ts` の `mainNavigation`・`helpNavigation` にまとめ、デスクトップのサイドバーとモバイルのドロワーで同じ `NavList` を使う。現在地は `isCurrentPath`（同じパスか、その下の階層）で判定する。
- ドロワーは Radix の `Dialog`（modal）。フォーカスの閉じ込め・Esc・背景のタップ・閉じた後のフォーカスの戻り先は Radix に任せ、リンクの選択と 1024px 以上への拡大（`matchMedia`）では明示的に閉じる。
- テーマ切り替えは 40px の ghost ボタンにし、設定を保存できないときの案内はボタンの下に重ねて表示する（トップバーの高さを変えない）。
- ナビ名の変更に合わせて、ガイド・端末・練習記録・README の「遊ぶ」「作成」「編集」「記録」を「練習する」「リストを作成」「単語リスト」「練習記録」に直した。
- 画面内の保存先バッジ（/create・/devices・/edit）は、保存操作のそばの説明として残している。
