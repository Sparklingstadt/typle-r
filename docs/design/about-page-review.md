## 現状の課題

| # | 優先度 | 課題 | 確認した内容 |
|---|---|---|---|
| 1 | P1 | 「GitHubでソースコードを見る」が開けない | リポジトリは非公開のため、ログインしていない訪問者やアクセス権のないアカウントには GitHub の 404 が出る（未ログインで確認）。同じタブで開き、外部サイトである印もない |
| 2 | P1 | 次に何をすればよいか分からない | ページの最後は GitHub へのリンクだけ。練習や使い方への導線がなく、アプリでできることの説明も1文だけ |
| 3 | P1 | 保存先の説明が1段落に詰まっている | 118文字の段落に、既定の保存先・ログイン時の保存先・分離の3点が入る。同期しないこと、ブラウザーのデータを削除すると消えることが書かれておらず、今どちらに保存しているかも分からない。390px では6行（144px） |
| 4 | P2 | 開発者向けの言葉が中心 | 「Next.jsとReactで開発」「Neon PostgreSQL保存」「分離されています」。利用者の判断に関係しない技術名が本文の中心にある |
| 5 | P2 | 送信する情報が書かれていない | 不具合の調査のためにエラー情報を送る仕組み（Sentry）があるが、何を送り、何を取り除くかの説明がアプリのどこにもない |
| 6 | P2 | バージョンが分からない | アプリ内にバージョンの表示がなく、不具合を伝えるときに確かめられない |
| 7 | P2 | 見出し・レイアウトが新デザインとそろっていない | 見出しは 30px・標準の太さで、カード1枚の古いレイアウト（/home・/guide と同じ）。1440px では本文が1行61文字（972px）で読みにくい |
| 8 | P2 | タブのタイトルがどの画面でも同じ | 「Typle \| 自分の言葉で、タイピング。」のままで、タブ・履歴・ブックマークで区別できない |

P1 = 迷い・手戻りが起きる／P2 = 見た目・情報設計（データ損失・操作不能につながる P0 はなし）

## 改善案

利用者が知りたい順（何ができるか → データはどこに残るか → 何が送られるか → バージョン）に並べ、/devices などと同じ見出し・幅にそろえた。

| 改善 | 対応する課題 | 内容 |
|---|---|---|
| 見出し・説明・主な行動 | 2, 7 | 太字 24px の見出しと1行の説明。「練習する」（塗り）と「使い方」（枠線）ですぐ始められる |
| できること | 2, 4 | リストを作成・練習する・ベスト記録の3枚。名前はサイドバー・各画面の見出しと同じ。見出しのリンクの押せる範囲をカード全体に広げ（読み上げはカードの名前だけ）、右上の › を目印にする。フォーカスでカード全体にリング、ホバーで枠が濃くなる |
| データの保存先を並べて比べる | 3, 4 | このブラウザー／アカウントの2枚に、保存する場所・同期・消える条件（アカウントは必要なもの）を同じ順で3行ずつ。今の保存先に「今の保存先」と濃い枠（`aria-current`）。ログイン状態の確認中はどちらにも付けない。詳しくは使い方の「保存について」（`/guide#storage`）へ |
| 不具合の報告 | 5 | 送る情報（エラーの内容と環境）と、送る前に取り除く情報（リクエストの内容・Cookie・ユーザー情報・操作の履歴）を明記 |
| バージョンと開発 | 1, 4, 6 | バージョン（`package.json` から）、使用している技術、ソースコード。技術名は本文から外してここにまとめる。GitHub は新しいタブで開き、外部リンクのアイコンと「非公開のリポジトリです。閲覧を許可されたGitHubアカウントでのみ開けます。」を付ける |
| 幅と1行の長さ | 7 | 本文は最大 896px（/devices と同じ）、説明文は最大 672px で1行48文字まで |
| ページのタイトル | 8 | 「Typleについて \| Typle」。description も /about 用にする |
| モバイル | 3, 7 | できることはアイコンを左に置き、1枚 102〜122px（3枚で 350px。アイコンを上に置くと 493px）。保存先の2枚は縦に並べ、「今の保存先」は名前の右。バージョンと開発は項目名の下に値 |

## 実装状況

v0.27.0 で実装。

- 画面: `src/app/about/page.tsx`（見出し・できること・不具合の報告・バージョンと開発、`metadata`）、`src/components/About/StorageComparison.tsx`（保存先の比較と今の保存先。`useSession` で判定し、確認中は印を出さない）
- `src/app/guide/page.tsx` の「保存について」に `id="storage"` を付け、/about からそこへ移れるようにした
- テスト: `tests/e2e/guest.spec.ts` に /about のテスト（タイトル、カードのリンク先、未ログインで「このブラウザー」が今の保存先、バージョン、GitHub を新しいタブで開く、`/guide#storage`、390px で横スクロールなし）。`tests/e2e/practice.spec.ts` の 1024×768 のテストは、/about が画面より長くなったため「内容より余分にスクロールしない」の確認に変え、ログイン中は「アカウント」が今の保存先になることを加えた

## 対象外

- サイドバーのヘルプにある「GitHub」も同じ非公開リポジトリを開くため、アクセス権のない人には 404 になる（共通レイアウトの変更になるため今回は触れていない。リポジトリを公開するか、ヘルプから外すかの判断が必要）
- /about 以外の画面の文書のタイトル（ほかの画面はクライアントコンポーネントで、共通のタイトルのまま）
