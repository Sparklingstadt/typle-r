## 改善案

| 改善 | 対応する課題 | 内容 |
|---|---|---|
| 一覧を枠に収める | 1, 2, 8 | 列を「時刻｜リスト・端末｜所要時間｜正確率｜1語あたり｜ミス｜削除」に整理し、最大960pxの枠に収める。列の見出しは一覧の上に1回だけ。数値は右寄せ・等幅数字。390px では横スクロールのない3行カード（リスト名とベスト／時刻・単語数・端末／所要時間・正確率・ミス）にし、1語あたりは sm 以上だけ |
| リスト・端末で絞り込む | 3 | 回数つきのメニュー（ピル型）。条件は URL（`?list=`・`?device=`）に残し、練習結果の「記録を見る」やホームからそのリストの履歴を直接開けるようにする。端末は記録に残る ID でまとめるので、改名・削除した端末も選べる。右に「17件 / 全44件」 |
| 日付ごとにまとめる | 3, 9 | 「今日・9月30日（水）」「昨日・…」の見出しに回数と合計時間。行には時刻だけを出す。50件ずつ表示し、続きは「さらに表示（残りN件）」 |
| 数値の表記をそろえる | 9 | 所要時間は「2分08.89秒」（60秒未満は「3.02秒」）、正確率は小数1桁。90%未満はオレンジ（ホームの「次に練習するリスト」と同じ基準）。1語あたりの秒数で、単語数の違うリストも比べられる |
| ベストの目印 | 10 | リストのベスト（正確率の高い順→所要時間の短い順で1位。ベスト記録の画面・練習結果と同じ決め方）に「ベスト」バッジ |
| リストのまとめと次の行動 | 10 | リストで絞り込むと、単語数・練習回数・最終日・ベストのカードに「練習する」（`/play?list=`）と「ベスト記録」。行の見出しは端末になり、同じリスト名が並ばない。記録のないリストでは、カードの代わりに空の状態から「このリストを練習する」 |
| 削除はアイコン | 7 | 40px のゴミ箱アイコン。普段はグレーで、ホバー時だけ赤（/devices と同じ） |
| 削除の確認に中身を出す | 4 | 「この練習記録を削除しますか？」に、リスト・日時・端末・所要時間・正確率・ミスを表示。ベストなら「削除すると、ベストは 3.09秒（100%）になります」 |
| 削除後のフォーカスと通知 | 5, 6 | 消した行の位置にある次の削除ボタンへフォーカスを移す（最後の行なら件数へ）。通知は「「Test 1」の練習記録（9月30日 01:46）を削除しました。」の1行に短縮 |
| 新デザインの枠組み | 11 | /devices と同じ見出し・説明・保存先バッジ。説明からベスト記録・ホームへリンク。空の状態はアイコン・説明・「練習する」 |
| 欠けた値の説明 | 9 | 古い記録の欠けた値は「—」にそろえ、表示中にあるときだけ下に注記。端末がない記録は「端末の記録なし」 |

並べ替えは設けない（ベスト順はベスト記録の画面、推移はホームが受け持つ）。

## 実装メモ

- 主な変更箇所: `src/app/(workspace)/records/page.tsx`、`src/components/Records/RecordRow.tsx`、`src/components/Records/FilterMenu.tsx`、`src/components/Records/ListSummary.tsx`、`src/lib/records.ts`、`src/components/DeleteConfirmation.tsx`
- `recordRows()` が全リストの記録を新しい順に並べ、各リストの1位（`bestRecords(records, 1)`）に `best` を付ける。`filterRows()`・`groupByDay()`（日付は閲覧者の現地時間）・`recordTimeParts()`・`formatAccuracy()` を `src/lib/records.ts` に追加。`recordTimeParts()` は先に1/100秒へ丸めるので、59.999秒は「60.00秒」ではなく「1分00.00秒」になる。
- 絞り込みは `useSearchParams` と `router.replace(..., { scroll: false })` で URL に保存する。`/play` と同じく Suspense で包む。
- `DeleteConfirmation` に `children`（説明とボタンの間に出す中身）を追加。
- 削除後のフォーカスは、開いたときの行の位置を覚えておき、`onCloseAutoFocus` で同じ位置の `[data-delete-record]` に移す。
- テスト: `tests/records.test.cjs` に並び順・ベスト・絞り込み（改名した端末と端末なし）・日付のまとまり・時間の表記、`tests/e2e/records.spec.ts` に日付の見出し・URL の絞り込み・リストのまとめ・ベスト削除の確認と削除後のフォーカス・50件ずつの表示・390px・空の状態を追加。一覧が表から list になったため、`guest.spec.ts`・`practice.spec.ts` の記録の探し方（`role="listitem"`）と空の状態の文言を更新。
